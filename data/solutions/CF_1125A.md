# Codeforces Round 1125 (Div. 3) A

- 平台：Codeforces
- 场次：Round 1125 (Div. 3)
- 题号：A
- 算法：数学、几何、构造
- 日期：2026-10-08

## 思路
一种很白痴的构造：直接输出点 (x, y+r)，即把圆上/内一个合法点构造出来，满足题目要求即可。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
//标签：数学、几何、构造
/*描述：一种很白痴的构造……*/ 
void solve(){
	int x,y,r;
	cin>>x>>y>>r;
	cout<<x<<" "<<y+r<<'\n';
}
int main(){
	int t; 
	cin>>t;
	while(t--){
		solve();
	} 
} 
```
