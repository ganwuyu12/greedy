# CF 1121A

- 平台：Codeforces
- 场次：Round 1121 (Div. 2)
- 题号：A
- 算法：构造，思维，排列
- 日期：2026-09-29

## 思路
核心是观察「错位元素必须全部选中」这一性质：把 p[i] != i 的位置全部取出，
这些元素必须一起被反转。检查取出的序列是否严格递减，若是则反转后恰好归位，
输出 YES；否则 NO。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
//标签：构造、思维、排列
/*核心是观察“错位元素必须全部选中”这一性质，然后检查反转后是否恰好归位*/ 
void solve(){
	int n;
	cin>>n;
	vector<int> p(n+1);
	vector<int> a;
	for(int i=1;i<=n;i++) cin>>p[i];
	int flag=1;
	for(int i=1;i<=n;i++){
		if(p[i]!=i){
			a.push_back(p[i]);
		}
	}
	for(int i=0;i<(int)a.size()-1;i++){
		if(a[i]<a[i+1]){
			flag=0;
		}
	}
	if(!flag){
		cout<<"NO"<<'\n';
	}else{
		cout<<"YES"<<'\n';
	}
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve();
	}
}
```
