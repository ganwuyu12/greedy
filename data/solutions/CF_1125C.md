# Codeforces Round 1125 (Div. 3) C

- 平台：Codeforces
- 场次：Round 1125 (Div. 3)
- 题号：C
- 算法：哈希表、组合计数、枚举、容斥
- 日期：2026-10-08

## 思路
统计相同「喜爱度」键的个数，用求无序对的方式得出候选答案：
- 令 sum = a[i] + a[i+2] - a[i+4]，以 sum 为键把下标 i 存入 map；
- 对每个键，其下标集合大小为 cnt，无序对数为 cnt*(cnt-1)/2；
- 但要减去用到重复键（下标相隔 2 或 4 会共用元素）的组合，用 unordered_set 快速检索 x+2、x+4 是否存在，统计需要扣除的对数 f。

答案累加 cnt*(cnt-1)/2 - f。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
//标签：哈希表 组合计数 枚举 容斥
/*描述：可以统计相同喜爱度键的个数，用求无序对的方式得出，
同时要记得减去用到重复键的组合，用 unordered_set能快速检索*/ 
void solve(){
	int n;
	cin>>n;
	vector<int> a(n);
	for(int i=0;i<n;i++) cin>>a[i];
	map<int,vector<int>> mp;
	for(int i=0;i<n-4;i++){
		int sum=a[i]+a[i+2]-a[i+4];
		mp[sum].push_back(i);
	}
	ll ans=0;
	for(auto &[k,v]:mp){
		int cnt=v.size();
		ll res=(ll)cnt*(cnt-1)/2;
		ll f=0;
		unordered_set<int> s(v.begin(),v.end());
		for(int x:v){
			if(s.count(x+2)) f++;
			if(s.count(x+4)) f++;
		}
		ans+=res-f;
	}
	cout<<ans<<'\n';
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int t;
	cin>>t;
	while(t--){
		solve(); 
	}
}
```
