# Codeforces Round 1125 (Div. 3) D

- 平台：Codeforces
- 场次：Round 1125 (Div. 3)
- 题号：D
- 算法：二分答案, 贪心, 分类讨论
- 日期：2026-10-08

## 思路
二分最终答案。

每次 check 时对每组独立贪心，算「提到目标值 x 的最小花费」，总花费不超过 k 则该答案可行。

- 若当前组三数之和已经 >= x，花费为 0。
- 否则设差值 d = x - sum，分情况讨论提升成本：
  - 三个数中存在严格最大者（`a>b||a>c||b>c` 等），此时提升一个数即可，花费 = d。
  - 三个数全相等，无法通过「抬低补高」制造差异，直接返回 false。
  - 否则需要先制造差异：枚举两种可能的「最小调整量」`cmp`，花费 = d + 2*cmp。

二分边界：[各组最小和, 最小和 + k]。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
int n;
ll k;
vector<ll> a,b,c;
//标签：二分答案 + 贪心 + 分类讨论
/*描述：二分最终答案，
每次 check 时对每组独立贪心算“提到目标值的最小花费”，
总花费不超过 k 就说明这个答案可行。 */
bool check(ll x){
	ll total=0;
	for(int i=0;i<n;i++){
		ll sum=a[i]+b[i]+c[i];
		if(x<=sum) continue;
		ll d=x-sum;
		ll cost;
		if(a[i]>b[i]||a[i]>c[i]||b[i]>c[i]){
			cost=d;
		}else if(a[i]==b[i]&&b[i]==c[i]){
			return false;
		}else{
			ll cmp=LLONG_MAX;
			if(a[i]<c[i]){
				cmp=min(cmp,b[i]-a[i]+1);
			}
			if(a[i]<b[i]){
				cmp=min(cmp,c[i]-b[i]+1);
			}
			cost=d+2*cmp;
		}
		total+=cost;
		if(total>k) return false;
	}
	return total<=k;
}
void solve(){
	cin>>n>>k;
	a.resize(n);
	b.resize(n);
	c.resize(n);
	ll ans=LLONG_MAX;
	for(int i=0;i<n;i++){
		cin>>a[i]>>b[i]>>c[i];
		ans=min(ans,a[i]+b[i]+c[i]);
	}
	ll l=ans;
	ll r=ans+k+1;
	while(l<=r){
		ll mid=l+(r-l)/2;
		if(check(mid)){
			ans=mid;
			l=mid+1;
		}else{
			r=mid-1;
		}
	}
	cout<<ans<<'\n';
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int t;
	cin>>t;
	while(t--){
		solve(); 
	}
}
```
