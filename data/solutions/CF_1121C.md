# CF 1121C

- 平台：Codeforces
- 场次：Round 1121 (Div. 2)
- 题号：C
- 算法：计数，组合数学，前缀积
- 日期：2026-09-29

## 思路
将「求每棵树的代价之和」转换为「求每条边出现在多少棵树中再累加」。
排序后建立后缀和 sum，前缀积 pre 与后缀积 suf 统计各位置作为边的组合数。
对每个相邻点对 i 计算 diff = sum[i+1] - (n-i-1)*a[i]，
权值 w = pre[i]*suf[i+1]，累加 w*diff 即为答案，模 998244353。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
const ll MOD=998244353;
//标签：计数 + 树 + 前缀技巧
/*将求每个树的代价的总和转换为求每条边出现在几个树再累加*/ 
void solve(){
	int n;
	cin>>n;
	vector<ll> a(n);
	vector<ll> sum(n); 
	ll ans=0;
	for(int i=0;i<n;i++) cin>>a[i];
	sort(a.begin(),a.end());
	sum[n-1]=a[n-1];
	for(int i=n-2;i>=0;i--){
		sum[i]=sum[i+1]+a[i];
	}
	vector<ll> pre(n,1),suf(n,1);
	for(int i=0;i<n-1;i++){
		pre[i+1]=pre[i]*(n-i-1)%MOD;
	}
	for(int i=n-2;i>=0;i--){
		suf[i]=suf[i+1]*(n-i-1)%MOD;
	}
	for(int i=0;i<n-1;i++){
		ll diff=((sum[i+1]-(n-i-1)%MOD*a[i])%MOD+MOD)%MOD;
		ll w=pre[i]*suf[i+1]%MOD;
		ll cost=w*diff%MOD;
		ans=(ans+cost)%MOD;
	}
	cout<<ans<<'\n';
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve();
	}
}
```
