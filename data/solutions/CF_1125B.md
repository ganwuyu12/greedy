# Codeforces Round 1125 (Div. 3) B

- 平台：Codeforces
- 场次：Round 1125 (Div. 3)
- 题号：B
- 算法：栈、模拟
- 日期：2026-10-08

## 思路
翻译题目操作即可。用栈维护待匹配的 '1' 位置：
- 遇到 '1' 入栈；
- 遇到 '2'，若栈非空则弹出栈顶并标记为已消除，否则标记当前位置已消除；
- 遇到 '3' 直接标记当前位置已消除。

最后统计未被标记的位置并输出（注意输出 1-based 下标）。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
//标签：栈、模拟
/*描述：翻译题目操作即可 */ 
void solve(){
    int n;
    cin>>n;
    string s;
    cin>>s;
    stack<int> q;
    vector<int> vis(n);
    for(int i=0;i<n;i++){
    	if(s[i]=='1'){
    		q.push(i);
		}else if(s[i]=='2'){
			if(!q.empty()){
				int cur=q.top();
			    q.pop();
			    vis[cur]=1;
			}else{
				vis[i]=1;
			}
		}else{
			vis[i]=1;
		}
	} 
	int cnt=0;
	for(int i=0;i<n;i++){
		if(vis[i]==0){
			cnt++;
		}
	} 
	cout<<cnt<<'\n';
	for(int i=0;i<n;i++){
		if(vis[i]==0){
			cout<<i+1<<" ";
		}
	}
	cout<<'\n';
}
int main(){
	int t; 
	cin>>t;
	while(t--){
		solve();
	} 
}
```
