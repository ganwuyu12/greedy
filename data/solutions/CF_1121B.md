# CF 1121B

- 平台：Codeforces
- 场次：Round 1121 (Div. 2)
- 题号：B
- 算法：贪心, 堆(优先队列), 前缀, 数学推导
- 日期：2026-09-29

## 思路
变化为 m*bi - b(i-1) - …… - b0，用优先队列维护前 m-1 个最大元素。
枚举 i 作为最后选中的下标，堆中维护其前面 m-1 个最大值，答案取 m*a[i] - sum 的最大值。
特判 m == 1 时答案为数组中最大值。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
//标签：贪心、堆（优先队列）、前缀、数学推导 
/*变化为 m*bi-b（i-1）-……-b0,用优先队列维护m-1最大堆*/
void solve(){
	int n,m;
	cin>>n>>m;
	vector<long long> a(n+1);
	for(int i=1;i<=n;i++) cin>>a[i];
	priority_queue<long long> pq;
	if(m==1){
		long long ans=*max_element(a.begin()+1,a.end()); 
		cout<<ans<<'\n';
		return;
	}
	long long ans=LLONG_MIN;
	long long sum=0;
	for(int i=1;i<=n;i++){
		if((int)pq.size()==m-1){
			ans=max(ans,1LL*m*a[i]-sum);
		}
		pq.push(a[i]);
		sum+=a[i];
		if((int)pq.size()>m-1){
			sum-=pq.top();
			pq.pop();
		}
	}
	cout<<ans<<'\n';
	
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve(); 
	}
}
```
