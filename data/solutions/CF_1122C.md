# Codeforces 1122C

- 平台：Codeforces
- 场次：Round 1122 (Div. 3)
- 题号：C
- 算法：动态规划
- 日期：2026-10-08

## 思路
通过观察可以发现题目操作与位运算无关，只要前面有 0 后面就可以操作为 0 或 1，同时发现第一位无法改变，
因此用 dp[i][j] 描述第 i 位尾数为 j 的单调数列即可。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;

//标签：动态规划
/*描述：通过观察可以发现题目操作与位运算无关，只要前面有0后面就可以操作为0或1，同时发现第一位无法改变，
因此用dp【i】【j】描述第i位尾数为j的单调数列即可 */
void solve(){
	int n;
	cin>>n;
	string s;
	cin>>s;
	vector<vector<int>> dp(n,vector<int>(2));
	if(s[0]=='1'){
		int cnt=0;
		for(int i=0;i<n;i++){
			if(s[i]=='0'){
				cnt++;
			}
		}
		cout<<cnt<<'\n';
	}else{
		for(int i=1;i<n;i++){
			if(s[i]=='0'){
				dp[i][0]=dp[i-1][0];
				dp[i][1]=min(dp[i-1][1],dp[i-1][0])+1;
			}else{
				dp[i][0]=dp[i-1][0]+1;
				dp[i][1]=min(dp[i-1][0],dp[i-1][1]);
			}
		}
		int ans=min(dp[n-1][0],dp[n-1][1]);
		cout<<ans<<'\n';
	}
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve();
	}
}
```
