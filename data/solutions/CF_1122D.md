# Codeforces 1122D

- 平台：Codeforces
- 场次：Round 1122 (Div. 3)
- 题号：D
- 算法：哈希（差值不变式），排序，连续段
- 日期：2026-09-24

## 思路
观察到对于同一斜线上的位置，`c = a[i] - i` 是定值。因此把所有 `a[i] - i` 收集起来，排序去重后找最长的整数连续段长度即为答案，相当于找最长的一条“平坦/可行”的斜线。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
void solve(){
	int n;
	cin>>n;
	vector<int> a(n);
	vector<int> c;
	for(int i=0;i<n;i++){
		cin>>a[i];
		c.push_back(a[i]-i);
	}
	sort(c.begin(),c.end());
	c.erase(unique(c.begin(),c.end()),c.end());
	
	int ans=0,cur=0;
	for(int i=0;i<c.size();i++){
		if(i==0){
			cur=1;
		}else{
			if(c[i]==c[i-1]+1){
				cur++;
			}else{
				cur=1;
			}
		}
		ans=max(ans,cur);
	}
	cout<<ans<<'\n';
	
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve(); 
	}
}
```
