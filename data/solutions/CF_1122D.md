# Codeforces Round 1122 (Div. 3) D

- 平台：Codeforces
- 场次：Codeforces Round 1122 (Div. 3)
- 题号：D
- 算法：观察，贪心，排序，去重
- 日期：2026-10-08

## 思路
观察到不变量 c：土堆高度与索引之差 a[i] - i 是一个定值。
因此连续平坦路段的 c 就是一个公差为 1 的单调递增序列。
将原数组处理成 c 数组后，排序并去重，贪心寻找最长的「连续 +1 递增」序列，其长度即为答案。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
//标签：观察，标签
/*这道题首先是观察到不变量c，即土堆高度和索引的差是一个定值，
从而连续平坦路段的c就是一个公差为1的单调递增序列，将原数组处理后贪心寻找最长递增序列即可*/ 
void solve(){
	int n;
	cin>>n;
	vector<int> a(n);
	vector<int> c;
	for(int i=0;i<n;i++){
		cin>>a[i];
		c.push_back(a[i]-i);
	}
	sort(c.begin(),c.end());
	c.erase(unique(c.begin(),c.end()),c.end());
	
	int ans=0,cur=0;
	for(int i=0;i<c.size();i++){
		if(i==0){
			cur=1;
		}else{
			if(c[i]==c[i-1]+1){
				cur++;
			}else{
				cur=1;
			}
		}
		ans=max(ans,cur);
	}
	cout<<ans<<'\n';
	
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve(); 
	}
}
```
